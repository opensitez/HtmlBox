@media + :is() — Responsive Two-Column Article

Responsive Layout

Column count is controlled by @media (min-width: 901px). Headings inside use :is(h3, h4) to share a single rule. Resize the window below 900px to collapse to one column.

The CSS cascade is the algorithm that determines which CSS rule applies to an element when multiple rules could match. It considers specificity, origin, importance, and source order.

Specificity

Specificity is calculated from selector parts: IDs contribute 100 points, classes and pseudo-classes 10 points, and element selectors 1 point. The higher the specificity, the higher the priority.

Inline styles bypass the cascade entirely and receive the highest specificity, just below !important declarations. Understanding specificity is essential to avoiding unexpected overrides.

Inheritance

Some CSS properties inherit their value from the parent element when no explicit value is set. Properties like color, font-family, and line-height inherit by default; box-model properties like margin and padding do not.

The inherit keyword forces inheritance for any property, and initial resets it to the property's default value. The unset keyword acts as inherit for inheritable properties and initial for others.

The :is() and :where() Functions

The :is() pseudo-class accepts a selector list and matches any element that matches any of the selectors. Its specificity equals the most specific selector in the list. :where() is identical but contributes zero specificity.

These functions dramatically reduce repetition when targeting multiple element types. Instead of writing separate rules for every heading level, a single :is(h1,h2,h3,h4) rule suffices.
