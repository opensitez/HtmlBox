Here's a summary of all the CSS features we support now. Scroll through:
✨ Feature Showcase
✅ overflow: hidden - clips content to padding box ✅ overflow: scroll - clips + shows scrollbar ✅ overflow: auto - scrollbar only when needed ✅ border-radius + overflow: hidden = rounded clipping ✅ max-height + overflow: auto = scrollable panels ✅ position: relative + negative top/left = overlapping elements ✅ float: left/right = classic column layouts ✅ clear: both = clearing floats ✅ display: flex = modern flexible layouts ✅ display: grid = CSS grid with columns/rows ✅ :hover pseudo-class = interactive state changes ✅ :active pseudo-class = pressed state styling ✅ box-shadow = drop shadows ✅ border-radius = rounded corners ✅ text-overflow: ellipsis = truncated text ✅ Custom components = <graph> tag with paint callback ✅ Event system = click, hover, drag, wheel ✅ Per-element scrolling = this very box!
